API Documentation

Complete reference for the ROMA Execution Bridge REST API. All endpoints return JSON. Base URL: https://api.roma.dev/v1

Overview

ROMA Execution Bridge is a multi-tenant GPU execution platform. Submit AI workloads — training, inference, batch processing — through a single REST API. Every request is authenticated, metered, and monitored.

◈
The API is versioned via the URL path. Current stable version: v1. Breaking changes trigger a new version.

Quick Start

1. Get your API key from the dashboard
2. Set the X-API-Key header
3. Submit your first job

bash
# Health check (no auth required)
curl https://api.roma.dev/v1/health

# Submit a training job
curl -X POST https://api.roma.dev/v1/submit \
  -H "X-API-Key: $ROMA_KEY" \
  -H "Content-Type: application/json" \
  -d '{"image":"pytorch/pytorch:2.1.0","command":"python train.py","gpu_type":"A100","gpu_count":1}'

Authentication

All authenticated endpoints require an X-API-Key header.

HeaderRequiredDescription
X-API-KeyYes*Your ROMA API key (/health excluded)
Content-TypeFor POSTMust be application/json
⚠
Never expose your API key in client-side code or version control. Use environment variables.

GET /health

Public health check. Returns cluster status and version.

response
{
  "status": "healthy",
  "version": "2.0.0",
  "gpu_available": 42,
  "uptime_seconds": 864000
}

POST /submit

Submit a new job for execution. Returns a job_id for tracking.

Request Body

FieldTypeRequiredDescription
imagestringYesDocker image for execution
commandstringYesCommand to run inside container
gpu_typestringNoGPU type (T4, A100, H100). Default: T4
gpu_countintNoNumber of GPUs. Default: 1
prioritystringNonormal / high. Default: normal
response 201
{
  "job_id": "job_kx9m2f",
  "status": "queued",
  "estimated_start_s": 12
}

GET /status/{job_id}

Get current status and details for a specific job.

response
{
  "job_id": "job_kx9m2f",
  "status": "running",
  "gpu_type": "A100",
  "started_at": "2026-08-19T18:30:00Z",
  "duration_s": 3600,
  "gpu_util_pct": 87.5,
  "memory_mb": 32768
}

GET /jobs

List all jobs for the authenticated tenant. Supports pagination.

Query ParamDefaultDescription
limit20Max results per page (max 100)
offset0Pagination offset
status—Filter: queued / running / done / failed

GET /usage

Current billing period usage and limits.

response
{
  "period_start": "2026-08-01T00:00:00Z",
  "period_end": "2026-09-01T00:00:00Z",
  "gpu_hours_used": 1240.5,
  "gpu_hours_limit": 5000,
  "cost_estimate_usd": "372.15"
}

DELETE /cancel/{job_id}

Cancel a queued or running job. Running jobs are terminated with SIGTERM.

response 200
{
  "job_id": "job_kx9m2f",
  "status": "cancelled",
  "billed_seconds": 2140
}

Examples

Python

python
import requests

API = "https://api.roma.dev/v1"
HEADERS = {"X-API-Key": "your-key"}

# Submit a job
resp = requests.post(f"{API}/submit", json={
    "image": "pytorch/pytorch:2.1.0",
    "command": "python train.py --epochs 10",
    "gpu_type": "A100",
    "gpu_count": 2
}, headers=HEADERS)

job_id = resp.json()["job_id"]

# Poll status
while True:
    s = requests.get(f"{API}/status/{job_id}", headers=HEADERS)
    if s.json()["status"] == "done":
        break

Node.js

javascript
const API = 'https://api.roma.dev/v1';
const headers = { 'X-API-Key': process.env.ROMA_KEY, 'Content-Type': 'application/json' };

const { job_id } = await fetch(`${API}/submit`, {
  method: 'POST', headers,
  body: JSON.stringify({ image: 'pytorch/pytorch:2.1.0', command: 'python train.py' })
}).then(r => r.json());

console.log(`Job submitted: ${job_id}`);
