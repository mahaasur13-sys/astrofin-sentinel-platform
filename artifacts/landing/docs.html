API Documentation

Complete reference for the AstroFin Sentinel + ROMA Execution Bridge REST API. All endpoints return JSON. Base URL: http://127.0.0.1:8080

Authentication

All authenticated endpoints require an X-API-Key header. Keys are hash-only (plaintext column deleted) and masked first4***last4.

HeaderRequiredDescription
X-API-KeyYes*Your API key (/health excluded)
Content-TypeFor POSTMust be application/json

GET /health

Public health check — no API key required.

curl http://127.0.0.1:8080/health # {"status":"ok","pg":true,"version":"2.1.0","pool":"2/10"}

POST /submit

Submit a job. Requires X-API-Key. Billing debit happens at completion, not at submit.

Request Body

{ "task": "echo hello", "backend": "gpu_worker" }
curl -X POST http://127.0.0.1:8080/submit \ -H "X-API-Key: YOUR_KEY" \ -H "Content-Type: application/json" \ -d '{"task":"echo hello","backend":"gpu_worker"}' # → 202 {"job_id":"…","tenant_id":"t-test-paper-20260909"}

GET /status/{job_id}

Get the current status of a job.

curl -H "X-API-Key: YOUR_KEY" http://127.0.0.1:8080/status/{job_id}

GET /jobs

List all jobs for your tenant.

curl -H "X-API-Key: YOUR_KEY" http://127.0.0.1:8080/jobs

GET /usage

Usage report for your tenant.

curl -H "X-API-Key: YOUR_KEY" http://127.0.0.1:8080/usage

GET /billing/balance · /billing/ledger

Billing balance and append-only ledger for your tenant.

curl -H "X-API-Key: YOUR_KEY" http://127.0.0.1:8080/billing/balance curl -H "X-API-Key: YOUR_KEY" http://127.0.0.1:8080/billing/ledger

Billing invariants — L1–L4

Every charge is governed by four hard invariants:

LayerGuarantee
L1Append-only ledger — INSERT only + trigger 009
L2Atomic debit — pg_advisory_xact_lock + WITH bal AS SUM(CREDIT-DEBIT) + WHERE bal>=amount
L3Idempotency — job:{id} sha256[:24] + PK 006
L4Fail-closed — 402/403/429/503
